# Tobin brand pack

- svg/: symbol (glossy; flat black, white, blue) and lockups. Lockup wordmarks are outlined (Aalto Display), so no font is needed.
- png/symbol, png/avatars, png/social, png/logo: raster exports.
- favicon/: favicon.ico (16/32/48), favicon.svg, apple-touch-icon, PWA icons, manifest, head snippet.
- colors.css: palette and font variables.

## Type
- Aalto Display: wordmark and headings (capitals only). Font files are not included; the uploaded file is the personal-use version, so a commercial licence is needed for the live logo and site.
- JetBrains Mono (400, 500): code, labels and technical text. Free on Google Fonts.

## Usage
Symbol minimum size 16px. Clear space = stroke width. Use flat versions for print and single-color contexts. The glossy mark needs a near-black or near-white ground.
