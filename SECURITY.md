# Security policy

Tobin Clearing Protocol is experimental. MVP-1 is a validation milestone: it uses test tokens only, is not production-ready, and has not been independently audited. Please read the README for its scope and limits.

## Reporting a vulnerability

Please report suspected vulnerabilities **privately** through GitHub private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe the issue.

Please include the affected commit or file, the steps to reproduce, and the impact you expect. Do not open a public issue or pull request for a suspected vulnerability, and please do not publish exploit details for software or services belonging to the project or its participants before the maintainers have had a chance to respond.

## Who receives reports

The repository owner, Ebubechi Ihediwa, monitors vulnerability reports submitted through GitHub for this repository.

## What is not promised

No response-time target, fix timeline, disclosure schedule, bounty or legal safe-harbour is offered by this document. Reports are handled on a best-effort basis by the owner.

## Scope

The contracts, TypeScript engine, SDK, local Console, tooling and documentation in this repository. Findings that depend on deployments the project did not make, or on real-value use (which the project does not support), are out of scope.
