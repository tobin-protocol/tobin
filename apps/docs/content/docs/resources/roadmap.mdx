| Milestone | Description | Status |
|---|---|---|
| MVP-1.2 | Clearing Operations Foundation | Completed |
| MVP-1.3 | Institutional Clearing Authorization | Completed |
| MVP-1.4 | Settlement Preparation Engine | Completed |
| MVP-1.5 | Stellar Settlement Integration | Completed with limitations |
| MVP-1.6 | Institutional Operations and Reconciliation | Planned |
| MVP-1.7 | Security, Governance and Infrastructure Hardening | Planned |
| MVP-1.8 | Controlled Institutional Pilot | Planned |

Wallet-first authentication and institutional onboarding were delivered after MVP-1.5 as a separate piece of work
(complete with limitations). It does not rename or reorder the milestones above.

<Callout type="warn" title="Completed does not mean production-approved">
  Completing MVP-1.5 means the Testnet integration was built and validated within a narrow, stated scope. The
  versioned-release and production gates in
  [`release/RELEASE-GATES.json`](https://github.com/tobin-protocol/tobin/blob/main/release/RELEASE-GATES.json) remain
  blocked, and real-value use is out of scope until the later milestones are delivered and independently reviewed.
</Callout>

Pilot readiness depends on MVP-1.6 to MVP-1.8 and an independent security review.

This page mirrors the roadmap in the repository README. If they differ, the README and the owner's milestone records
win; report the discrepancy.
