Run workspace scripts from the repository root with `npm run <script> --workspace <name>`.

## Root

| Script | What it does |
|---|---|
| `npm run typecheck` | Runs `typecheck` in every workspace that defines it. |
| `npm test` | Runs `test` in every workspace that defines it. |
| `npm run build:console` | Production build of the web console. |
| `npm run validate:signers` | Runs `scripts/multisig/validate-signers.mjs`. |
| `npm run multisig:inspect`, `multisig:prepare`, `multisig:verify` | Owner-run multisig tooling. Testnet only; needs the owner's authorisation. |

## tobin-web-console

| Script | What it does |
|---|---|
| `dev` | `next dev` on `127.0.0.1:8787`. |
| `build`, `build:console` | `next build`. |
| `start` | `next start` on `127.0.0.1:8787`. |
| `typecheck` | `tsc --noEmit`. |
| `test`, `test:unit` | `node --test` suites. |
| `test:browser`, `test:w0-browser`, `test:sessions-browser`, `test:settlement-browser`, `test:authorization-browser`, `test:clearing-browser`, `test:backend-browser` | Real-browser journeys (need a production build). |
| `db:migrate`, `db:status`, `db:seed-demo` | Database operator commands. |

## tobin-mvp1-sdk

| Script | What it does |
|---|---|
| `typecheck` | `tsc --noEmit`. |

| Script | What it does |
|---|---|

| `build` | `next build`. |

| `typecheck` | `next typegen && tsc --noEmit`. |

## Cargo (in `contracts/`)

```bash
cargo test --locked --workspace
cargo build --locked -p tobin-clearing-v1 --example bridge
stellar contract build
```

Repository-level checks: `node scripts/ci/check-links.mjs`, `node scripts/ci/update-npm-baseline.mjs --check`,
`node --test scripts/release/scan.test.mjs`.
