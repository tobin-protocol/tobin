## Instruction files

| File | Applies to |
|---|---|
| [`AGENTS.md`](https://github.com/tobin-protocol/tobin/blob/main/AGENTS.md) | the whole repository; authoritative for AI coding agents |
| [`CLAUDE.md`](https://github.com/tobin-protocol/tobin/blob/main/CLAUDE.md) | a short entry point that defers to `AGENTS.md` |
| `apps/landing/AGENTS.md` | the landing page only (its Next.js version differs from common knowledge) |
| `apps/docs/AGENTS.md` | this docs site only; defers to the root `AGENTS.md` |

## What not to edit casually

The root `docs/` directory holds accepted milestone records, audits, threat models, Testnet evidence and the contract
reference. Do not rename, move or rewrite them to make them look current; correct a factual error with a clearly
marked note, or write a new record. See [Documentation governance](/docs/resources/documentation-governance).

Also treat as protected: `contracts/deployments/testnet.json`, the Testnet evidence, the release gate definitions
(`release/RELEASE-GATES.json`) and the dependency baseline (`ci/dependency-baseline.csv`, which is regenerated with
`node scripts/ci/update-npm-baseline.mjs` when dependencies change).
