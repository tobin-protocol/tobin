# Console screenshots

The four `console-*.webp` files are crops of screenshots produced by the web console's own browser journeys (`apps/web-console/test/browser/clearing-journey.mjs`, `authorization-journey.mjs` and `settlement-journey.mjs`, run at 1200 px wide against a throwaway database). The data is fictional demonstration data (Alice, Bob and Carol at "Alpha Bank"). They show the local sandbox console, not a deployment, and no wallet, network or real value is involved.

They were cropped to avoid long placeholder account addresses and converted to WebP. Regenerate them from the journeys if the console UI changes materially; do not edit them by hand and do not add third-party photographs or logos here without a verified licence.
